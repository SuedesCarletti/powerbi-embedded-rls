## 🔐 4. CONTROLE DE ACESSO E PERMISSÕES

### 📍 Arquivo: `auth.py` - Verificação de Acesso

**Localização:** Função `user_can_access_report()` - Linha 160

```python
def user_can_access_report(report_name_or_id):
    # ✅ LÓGICA DE ACESSO ESTÁ AQUI
    
    # Admin sempre pode acessar tudo (linha ~175)
    if 'admin' in user_roles:
        return True
    
    # Verificar se tem acesso a todos os relatórios (linha ~180)
    if 'all' in user_reports:
        return True
    
    # ✅ ADICIONAR AQUI - Lógica personalizada de acesso
    # Exemplo: Vendedores só veem relatórios da própria região
    if 'salesman' in user_roles:
        if user_region == 'SP' and report_name_or_id in ['vendas_sp', 'clientes_sp']:
            return True
        return False
```

### 📍 Arquivo: `config.py` - Relatórios por Usuário

**Localização:** Função `get_reports_for_user()` - Linha 230

```python
def get_reports_for_user(user_roles, user_region):
    # ✅ LÓGICA DE FILTRO POR ROLE/REGIÃO ESTÁ AQUI
    
    for report_name, config in reports.items():
        # Verificar roles (linha ~240)
        required_roles = config.get('required_roles', [])
        if required_roles and not any(role in user_roles for role in required_roles):
            continue
        
        # ✅ ADICIONAR AQUI - Lógica personalizada
        # Exemplo: Regra especial para região Sul
        if user_region in ['RS', 'SC', 'PR'] and config['category'] == 'regional_sul':
            accessible_reports[report_name] = config
```
